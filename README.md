# Holidaze
![image alt](https://github.com/SidraShahid0510/Holidaze/blob/main/holidaze-image.jpg?raw=true)

Holidaze is a modern venue booking web application.It allows users to browse, search, and book venues, while venue managers can create and manage their own listings.

## Features

- User registration and login
- Customer and venue manager account types
- Browse venue listings
- Search venues
- View detailed venue pages
- Book venues with date and guest selection
- Prevent booking unavailable/past dates
- Customer profile with bookings
- Venue manager profile with created venues
- Create, edit, and delete venues
- View customer bookings for owned venues
- Edit avatar and banner image
- Responsive design for mobile, tablet, and desktop
- Toast feedback messages
- Loading skeleton states

## Built with

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- React Day Picker
- React Hot Toast
- Lucide React
- React Icons

## Intallation

### Clone the repository

git clone https://github.com/SidraShahid0510/Holidaze.git

### Install dependencies

```bash
 npm install
```

## Running the Project

### Development mode

```bash
npm run dev
```

## Installed Packages

### Dependencies

#### Install React and Router

```bash
npm install react react-dom react-router-dom
```

#### Install HTTP client(API calls)

```bash
npm install axios
```

#### Install date picker

```bash
npm install react-day-picker
```

#### Install toast notifications

```bash
npm install react-hot-toast
```

#### Install icons

```bash
npm install react-icons lucide-react
```
### Dev Dependencies
#### Install Vite and React Plugin

```bash
npm install -D vite @vitejs/plugin-react
```
#### Install TypeScript

```bash
npm install -D typescript @types/react @types/react-dom @types/node
```
#### Install Tailwind

```bash
npm install -D tailwindcss postcss autoprefixer
```
